# 三餐轻盈

一个本地优先、无需登录的三餐饮食习惯 PWA。可在 iPhone Safari 中打开并添加到主屏幕。

## 功能

- 早餐、午餐、晚餐分别打卡
- 餐盘结构、食物内容与饱腹感记录
- 近 7 天完成趋势和连续完成天数
- 可选体重记录与简单趋势提示
- 自定义三餐时间
- 本地数据备份导出
- 离线使用与主屏幕安装

## 隐私

所有饮食和体重记录仅存储在当前浏览器的本地存储中，不需要账号，也不会上传到服务器。清除浏览器网站数据会删除记录。

## 本地运行

请通过任意静态文件服务器打开项目目录，不要直接双击 `index.html`，以便测试 Service Worker。
