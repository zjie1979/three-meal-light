# 三餐九选

一个本地优先、无需登录的减脂饮食 PWA。先自定义 9 套餐，再为每天的早餐、午餐、晚餐分别任选一套，可在 iPhone Safari 中添加到主屏幕。

## 功能

- 固定 9 个餐方案位，每套可修改图标、名称、食物搭配和减脂提醒
- 每天早餐、午餐、晚餐从 9 套里任意选择，允许重复
- 三餐完成打卡、实际食物和饱腹感记录
- 近 7 天趋势、连续完成天数和历史套餐名称
- 可选体重记录与简单趋势提示
- 自定义三餐时间、本地备份导出和离线使用
- 自动兼容并迁移旧版“三餐轻盈”的本地记录

## 隐私

所有饮食、体重和自定义餐方案仅存储在当前浏览器，不需要账号，也不会上传到服务器。清除浏览器网站数据会删除记录。

## 本地运行

请通过任意静态文件服务器打开项目目录，不要直接双击 `index.html`，以便测试 Service Worker。
